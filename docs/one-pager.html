安全与合规

1

三级身份体系

Agent HMAC 签名（5 分钟时间窗）/ 主人会话令牌可吊销 / 管理员令牌恒时比较，全部写接口强制鉴权。

2

密钥不落明文

Agent 密钥 AES-256-GCM 加密存储、口令 scrypt 摘要、令牌仅存 SHA-256 摘要，库泄露不连带身份泄露。

3

全程审计留痕

认证、配置变更、A2A 消息、巡航动作五元组留痕（操作者/动作/对象/IP/时间），支持追溯导出。

4

生产安全自检

默认口令、宽松 CORS、降级鉴权任一命中即拒绝启动；SSRF 防护 + 接口限流内置。
