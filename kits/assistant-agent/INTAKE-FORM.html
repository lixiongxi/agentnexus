企业全能助理 · 信息收集表

为了让您的专属智能助理（秘书 + 客服 + 销售）一次配置到位，请 IT 与业务双方共同填写本表并回传。全部内容仅用于助理配置，双方可另行签署保密协议。

填写耗时约 30 分钟IT 与业务各填一半回传后 1~2 天交付
填写说明：带 * 为必填；不确定的条目可先留空并在回传时备注，我们会在 30 分钟对齐会上逐条确认。

1企业与助理定位 *

业务负责人填写：决定助理在平台上的身份与首要职责
企业名称 *

预计日均消息量（条/天）例：200 条以内 / 200–1000 / 1000 以上
最希望助理先胜任的一件事 *例：先做好产品咨询应答，两周后再开销售线索登记

2知识库现状（客服能力）*

业务负责人填写：FAQ 与标准答案从哪里来
知识库文档来源与格式 *例：Word 产品手册 3 份 / 客服 FAQ Excel / 无，需协助整理
高频问题 Top 5（尽量列举）*例：退货政策？保修几年？发货时效？
知识库更新频率与更新人
标准答复中不可承诺的内容（合规红线）例：不可承诺具体赔偿金额

3秘书服务范围（秘书能力）

行政/IT 共同填写：不启用秘书能力可整节跳过

该系统是否提供开放 API？（有 / 无 / 不确定）

4销售资料（销售能力）

销售负责人填写：不启用销售能力可整节跳过
产品目录（名称 + 一句话卖点 + 价格区间）例：智能会议屏 V5｜4K 触控内置投屏｜¥8,999 起
对外报价口径与折扣权限例：助理只报目录价，折扣一律转人工
现有 CRM 系统名称与版本
CRM 是否提供开放 API？（有 / 无 / 不确定）
线索必填字段（姓名 / 电话 / 意向产品…）

5数据源与权限

IT 负责人填写：决定助理能读什么、能写什么
允许助理读取的系统与数据
允许助理写入的系统与操作例：仅允许创建工单与线索，禁止改动订单
明确禁止接触的数据

数据是否允许出企业内网？*涉及私有化部署方案选型，必填

IT 负责人填写
