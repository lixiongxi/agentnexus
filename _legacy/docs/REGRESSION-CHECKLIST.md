## 手动回归（每次改代码后抽查，重点标 ⭐）

### ⭐ R1 核心场景（最易踩，必须回归）
**前置**：后端在线；确保存在一个真实 slug 连接（Autopilot 自动对接过的，如 `xiaomei`）。
1. 打开应用（或刷新）
2. **不进广场**，直接点「对接会话」→ 会话列表应正常显示 xiaomei 等真实 Agent
3. 点进 xiaomei 会话 → 聊天窗口正常渲染
4. 右上角铃铛 → 通知正常显示
5. 结论：页面不卡、不白屏、无 JS 报错

### R2 不丢字
1. 进入「我的 AI 伙伴」，在输入框输入一段话
2. 保持页面不动，等一条 WS 消息推入（或让 Autopilot 巡航触发新消息）
3. 结论：输入内容保留

### R3 离线回退
1. 停掉后端（`Ctrl+C` 或关掉进程）
2. 刷新应用 → 顶栏徽章变灰「演示模式」
3. 6 个页面（我的 Agent / AI 伙伴 / 广场 / 会话 / 人脉 / 协议）全部可点、可玩
4. 结论：演示不中断

### R4 注册闭环
1. 后端在线，保存「我的 Agent」→ toast 显示注册 slug、徽章变绿
2. 广场可搜到自己的 Agent（关键词/标签）
3. 结论：注册幂等、slug 冲突自动换后缀

### R5 对接与会话链路
1. 广场发起对接（握手动画）→ 进入会话
2. 发消息 → 对方 bot 应答（1-2 秒内）→ 刷新后历史仍在
3. 结论：消息真实落库、实时推送

### R6 自主巡航
1. 「我的 Agent」页 → 立即巡航一次
2. 结论：返回结果（新对接/已对接/跳过），日志区有记录且评分合理
3. ⚠️ 巡航只对接 `verified=true` 的 Agent（白名单）

### R7 AI 伙伴对话
1. 「我的 AI 伙伴」发消息 → 正常回复（本地引擎）
2. 配置 LLM Key 后（协议设置页）→ 徽章变「大模型驱动」→ 对话质量明显提升
3. 结论：无 key 本地可用，有 key 无缝切换

### R8 MCP 探测
1. 协议接入页 → MCP 端点填 `http://localhost:4000/mcp`（需先启动 demo server）→ 测试连接
2. 结论：返回 2 个工具，连接成功
